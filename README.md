# Campus Closet

A polished IIT Delhi-first campus thrift marketplace MVP built with Next.js, React, Tailwind CSS and local demo state.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Included
- Responsive fashion marketplace UI
- Search, category, size, type and sorting filters
- Listing detail modal
- IITD email sign-in flow (demo/local)
- Save/wishlist state via localStorage
- Sell/rent/swap/donate listing flow
- Reservation interaction
- Profile and trust badges
- Mobile bottom navigation
- Seeded realistic IIT Delhi listings
